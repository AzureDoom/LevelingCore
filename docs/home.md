# Welcome to the LevelingCore Wiki.

This documentation covers the configuration of LevelingCore, a flexible and scalable leveling system for Hytale servers.

Whether you’re running a small survival server or a large progression-based network, this wiki will help you configure LevelingCore to fit your needs.

## Getting Started

First, download the mod from [Modtale](https://modtale.net/mod/levelingcore) or [CurseForge](https://www.curseforge.com/hytale/mods/levelingcore) and install by following our [Installation Guide](https://wiki.hytalemodding.dev/mod/levelingcore/installation).

Then start [here](https://wiki.hytalemodding.dev/mod/levelingcore/internal-configuration) to learn the configuration of LevelingCore.
